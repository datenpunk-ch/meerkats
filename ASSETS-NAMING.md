# Assets naming + drop-in checklist

## Folder convention (this project)
- Put **photos** in `pics/`
- Put **charts/graphics** in `figures/`

## Filenames already referenced by the article
If you use these exact names, the Markdown + HTML will render without edits:

### Model plot (generated figure)
- `figures/CallProportions.png` (generated by `scripts/b_prop_interactive.R`)

### Figures (`figures/`)
- `fig01-activity-budget.png`
- `fig02-interaction-network.png`
- `fig03-seasonal-timeline.png`

### Photos (`pics/`)
- `photo01-sentinel.jpg`
- `photo02-pup-care.jpg`

## Recommended export settings
- **Charts**: PNG, 1600–2400px wide (or SVG if your site supports it)
- **Photos**: JPG, 1600–2400px wide, 80–85% quality
